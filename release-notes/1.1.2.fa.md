### تازه‌ها

- برنامه هر روز یک بار بررسی می‌کند که نسخهٔ تازه‌ای منتشر شده است یا نه. اگر آمده باشد، تغییراتش را نشان می‌دهد و با یک دستور، پس از گرفتن پشتیبان، مستقیم به آخرین نسخه می‌رود. این بررسی را در تنظیمات می‌توانید خاموش کنید.
- پس از هر به‌روزرسانی، تغییرات همین پنجره نشان داده می‌شوند و صفحه خودش نسخهٔ تازه را بارگیری می‌کند.
- نوار کناری نشان می‌دهد مدل واقعاً در دسترس است یا نه: اجرا نبودن Ollama، نصب نبودن مدل یا نبودن کلید API به‌جای «سرویس آماده است» نوشته می‌شود.
- یادداشت‌های سخنران در پاورپوینت، فایل‌های CSV و TSV به‌شکل جدول، و پیش‌نمایش تصویرهای بارگذاری‌شده هم خوانده و نمایش داده می‌شوند.

### رفع اشکال

- پاسخ به زبان پرسش نوشته می‌شود، حتی وقتی اسناد به زبان دیگری هستند.
- پیام‌های شما در سمتی می‌نشینند که زبانشان از آن شروع می‌شود: فارسی در راست و انگلیسی در چپ.
- بدون کلید API نمی‌توان به یک API بیرونی وصل شد، و هر کلید فقط به نشانی خودش فرستاده می‌شود.
- پس از بارگیری دوبارهٔ صفحه، همان گفت‌وگویی باز می‌شود که باز بود، و پاسخی که تازه تمام شده از دست نمی‌رود.
- متنی که پیش از قطع اتصال رسیده بود حفظ می‌شود، و پاسخ‌های طولانی پیش از پایان کار قطع نمی‌شوند.
- حذف گفت‌وگو وقتی سرویس در دسترس نیست هم انجام می‌شود. دو زبانهٔ باز هم دیگر تغییرات یکدیگر را پاک نمی‌کنند.
- میان‌برهای صفحه‌کلید با چینش فارسی هم کار می‌کنند.

### امنیت

- کتابخانهٔ filelock برای رفع یک آسیب‌پذیری امنیتی به‌روز شد.
- درخواست‌ها به API مدل دنبال تغییرمسیر نمی‌روند و به نشانی‌های ممنوع شبکه (مانند سرویس metadata ابری) نمی‌رسند، و کلید API هنگام راه‌اندازی هم به نشانی دیگری فرستاده نمی‌شود.
