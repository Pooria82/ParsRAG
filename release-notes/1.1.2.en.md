### New

- Once a day the app checks whether a newer version is out. If one is, it shows what changed and moves straight to the latest version with one command, after taking a backup. You can turn the check off in Settings.
- After every update, this window shows what changed, and the page loads the new version by itself.
- The sidebar shows whether the model can actually answer: when Ollama is not running, the model is not installed, or no API key is set, it says so instead of "Service ready".
- PowerPoint speaker notes, CSV and TSV files as tables, and previews of uploaded images are now read and shown.

### Fixed

- Answers are written in the language of the question, even when the documents are in the other language.
- Your messages sit on the side their language starts from: Persian on the right, English on the left.
- An external API cannot be connected without an API key, and each key is only sent to its own address.
- After a reload the conversation that was open opens again, and an answer that just finished is not lost.
- Text that already arrived is kept when the connection drops, and long answers are no longer cut off while the model is still working.
- Deleting a conversation works while the service is offline. Two open tabs no longer overwrite each other.
- Keyboard shortcuts work with the Persian keyboard layout.

### Security

- filelock is upgraded to fix a security vulnerability.
- Model API requests never follow redirects or reach blocked addresses such as cloud metadata services, and an API key is never sent to another address, also at startup.
